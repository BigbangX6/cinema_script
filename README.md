# cinema_script
Préparer votre découpage technique, envoyer le à votre équipe, improviser et noter les prises sur le tournage, puis retrouver tout au montage. PWA disponible hors-connexion.

## Version One App

Cinema Script existe aussi en app [One App](https://github.com/BigbangX6/One-App) (projets dans Google Drive, travail en équipe, hors-ligne) : voir [`oneapp/`](oneapp/README.md).
