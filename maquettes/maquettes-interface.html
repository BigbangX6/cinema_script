Trois maquettes pour le plateau

Mêmes données, même logique Séquence › Plan (prévu / impro) › Prise + clap audio. Les maquettes sont cliquables : jouez le clap, donnez un avis, changez de plan. Les données sont un exemple (« Les Heures Creuses ») et rien n'est enregistré.

Principes communs

  • Deux gestes par prise : Clap, puis un appui sur l'avis. L'avis enregistre la prise ; la note se tape après, sans bloquer.
  • Le numéro de prise est toujours visible en grand, comme sur un vrai clap : c'est l'information qu'on vérifie le plus.
  • Couleur = avis (Master, OK, Moyen, Bof, KO, À vérifier) partout : liste des prises, points du découpage, planning.
  • Orange = impro, uniquement. Vert/turquoise = action principale. Le reste reste neutre.
  • « Annuler » dans un bandeau plutôt qu'une fenêtre de confirmation pour une prise (plus rapide, et le clap reste juste).

Statut d'un plan

  • À tourner : aucune prise.
  • En cours : des prises, mais aucune OK ni Master.
  • Tourné : au moins une prise OK ou Master.
  • Calculé à partir des prises : aucun champ nouveau dans le fichier.

Pour l'implémentation

  • Le format sequences / plans / takes / tournageList et les libellés d'avis ne changent pas : l'extension Premiere continue de fonctionner.
  • DigitalClapper est repris tel quel (le clap de ces maquettes joue le vrai signal).
  • A et B peuvent coexister : même code, la mise en page change selon la largeur d'écran (A sous 860 px, B au-dessus).
